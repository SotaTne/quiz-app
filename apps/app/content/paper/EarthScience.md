# 第1章 地球の誕生・惑星の温度（第1回）

## 地球の形成と大気の変化

```text
分子雲 → 分子雲コア → 原始太陽
                     └→ 原始太陽系円盤 → 微惑星 → 原始惑星 → 惑星
```

| 用語 | 答え |
|---|---|
| 分子雲 | 星間ガスとチリからなる雲 |
| 分子雲コア | 分子雲の密度が高い部分。万有引力でさらに物質を集める |
| 1次原始大気 | 分子雲由来。水素・ヘリウムが主成分 |
| 地球型惑星 | 水星・金星・地球・火星。固体の地面を持つ |
| 木星型惑星 | 木星以遠。水素・ヘリウムに富む大気を維持 |
| 衝突脱ガス | 微惑星の衝突で、固体に含まれたガス成分が放出されること |
| 2次原始大気 | 水蒸気 → 二酸化炭素 → 窒素の順に多い。SO₂・HClも含む |

```text
水蒸気 → 海
二酸化炭素 → 海に溶解 → CaCO₃ → 石灰岩として固定
窒素 → 現在の大気の主成分として残る
```

- 原始の海が強酸性：SO₂とHClが溶けたため。
- 雨が陸地を浸食し、岩石中のナトリウム・カルシウムが海へ → 中和・海が塩辛くなる。
- シアノバクテリアの光合成：約27億年前から酸素を生成。
- 酸素増加 → オゾン増加 → 紫外線減少 → 約4.3億年前に陸上進出。
- 石炭：古代の植物由来。巨大森林が存在した証拠。

## 放射平衡・温室効果

- 放射平衡：太陽から吸収するエネルギーと、宇宙へ放出する赤外線エネルギーがつり合う状態。
- 有効放射温度 Te：放射平衡で決まる温度。
- アルベド A：太陽光の反射率。吸収率は `1 − A`。
- 温室効果気体：可視光をほぼ吸収せず、赤外線を強く吸収する。水蒸気、CO₂、メタン。

| 惑星 | アルベド | 有効放射温度 | 表面温度 |
|---|---:|---:|---:|
| 金星 | 0.78 | 224 K | 730 K |
| 地球 | 0.30 | 255 K | 288 K |
| 火星 | 0.16 | 216 K | 210 K |

金星は反射率が高いので有効放射温度は低い。それでも表面が高温なのは強い温室効果のため。

$$
B(T)=\sigma T^4
$$

温度が2倍なら放射エネルギーは16倍。

$$
T_e=\left(\frac{S(1-A)}{4\sigma}\right)^{1/4}
$$

$$
T_s=\sqrt[4]{2}\,T_e\approx1.19T_e
$$

地球の単純モデル：255 K → 約303 K → 約30 ℃。

# 第2章 大気・海洋の循環と天気（第2〜4回）

## 風と大気循環

```text
温度差 → 密度・気圧差 → 気圧傾度力 → 風
```

- 気圧傾度力：高気圧から低気圧へ、等圧線に垂直に働く力。
- 等圧線が狭いほど気圧傾度力が強く、風が強い。
- 暖気：密度が小さく上昇。寒気：密度が大きく下降。
- 海陸風：昼は海→陸の海風、夜は陸→海の陸風。
- 季節風＝モンスーン：大陸と海洋の季節的温度差による大規模な風。
- 3細胞循環：低緯度から **ハドレー循環 → フェレル循環 → 極循環**。
- 大気・海洋の共通の仕事：低緯度から高緯度へ熱を運び、温度差をならす。

| 海洋循環 | 原因 | 例 |
|---|---|---|
| 風成循環 | 海面を吹く風 | 黒潮・メキシコ湾流 |
| 熱塩循環 | 水温・塩分による密度差 | 深層循環、約2000年で一周 |

低温・高塩分の海水ほど密度が大きく、深海へ沈む。

## コリオリ力・地衡風・偏西風

- コリオリ力：地球自転による見かけの力。北半球では進行方向の右、南半球では左。赤道ではゼロ。
- 小規模の海陸風：コリオリ力をほぼ無視し、高→低へ吹く。
- 地衡風：上空で気圧傾度力とコリオリ力がつり合う風。等圧線にほぼ平行。
- 北半球の地衡風：高気圧を右、低気圧を左に見る。
- 偏西風：中緯度で平均的に西から東へ吹く大規模な風。蛇行する。
- 上空では暖かい南側が相対的高圧、冷たい北側が相対的低圧 → 地衡風として偏西風。
- 摩擦風：地上付近では摩擦で風速・コリオリ力が弱まり、等圧線を横切って低気圧へ吹き込む。

```text
摩擦収束 → 上昇流 → 断熱冷却 → 水蒸気の凝結 → 雲・雨
```

## 前線・温帯低気圧

| 前線 | 暖気の上昇 | 雨 |
|---|---|---|
| 寒冷前線 | 寒気に急に押し上げられる | 狭い範囲・強い・短い |
| 温暖前線 | 寒気の上を緩やかに上昇 | 広い範囲・弱い・長い |

- 気圧の谷：偏西風が南へ下がる部分、上空の低気圧。
- 気圧の尾根：偏西風が北へ上がる部分、上空の高気圧。
- 傾圧不安定：中緯度で偏西風が蛇行し、温帯低気圧・移動性高気圧が波として発達する現象。中緯度の熱輸送を担う。

## 積乱雲・豪雨・台風

```text
暖かく湿った空気が上昇
→ 断熱冷却
→ 水蒸気が凝結
→ 潜熱を放出
→ 上昇流が強まり積乱雲が発達
```

- 潜熱：水蒸気が水滴へ**凝結**するときに放出される熱。凝固ではない。
- 積乱雲：寿命約1時間、水平規模約5〜10 km。
- クラウドクラスター：積乱雲の集団、数百km規模。
- 線状降水帯：同じ場所で積乱雲が次々に発生し、強雨が長時間続く。
- スーパーセル：長時間持続する強い積乱雲。メソサイクロンを持ち竜巻を起こすことがある。
- ダウンバースト：積乱雲から地表へ吹き下ろす強い下降流。直径4 km以下はマイクロバースト。

| 用語 | 答え |
|---|---|
| 台風 | 北西太平洋で最大風速17.2 m/s以上の熱帯低気圧の名称 |
| ハリケーン | 北東太平洋・カリブ海・北大西洋の熱帯低気圧 |
| サイクロン | ベンガル湾・アラビア海の熱帯低気圧 |
| 発達条件 | 海水温約27 ℃以上、豊富な水蒸気・潜熱 |
| CISK | 潜熱を使う上昇流と低圧化が互いを強める台風発達機構 |
| 台風の眼 | 中心の比較的静かな領域 |
| 眼の壁雲 | 眼の周囲の最も激しい積乱雲 |
| レインバンド | 中心の周囲にらせん状に伸びる降水帯 |

台風は暖かい海からの水蒸気供給が減ると衰弱。中緯度で温度差をエネルギーにする低気圧へ変化するのが温帯低気圧化。

# 第3章 ENSOと地球環境問題（第5〜6回）

## ENSO

通常時、赤道太平洋の貿易風は **東→西**。暖水は西太平洋へ集まり、ペルー沖では湧昇流が起きる。

```text
貿易風が東→西
→ ペルー沖の表層水が沖へ運ばれる
→ 深海の冷たく栄養豊富な水が上昇
→ プランクトン・魚が増え、漁場になる
```

| 用語 | 答え |
|---|---|
| エクマン輸送 | 風とコリオリ力で海水が風向からずれて運ばれる現象 |
| 沿岸湧昇流 | 沿岸で表層水が沖へ運ばれ、深海水が上昇 |
| 赤道湧昇流 | 赤道の両側へ表層水が離れ、深海水が上昇 |
| エルニーニョ | 数年に一度、約1年続く赤道太平洋中東部の高温状態。貿易風・湧昇流が弱い |
| ラニーニャ | 貿易風・湧昇流が強く、赤道太平洋中東部が低温 |
| 南方振動 | タヒチとダーウィンの気圧の逆相関 |
| ENSO | エルニーニョ／南方振動。海洋と大気の相互作用 |

- エルニーニョ時の日本：暖冬の傾向。
- ラニーニャ時の日本：猛暑の傾向。ただし必ずではない。
- テレコネクション：加熱・冷却の影響が大気の**波**として遠方へ伝わる現象。
- PNA：Pacific North America。太平洋から北米。
- PJ：Pacific Japan。西太平洋から日本付近。
- シルクロードパターン：西アジアからユーラシアを経て日本付近へ。

## 地球温暖化・オゾンホール・ヒートアイランド

| 現象 | 主因 | 結果 |
|---|---|---|
| 地球温暖化 | CO₂など温室効果気体、人為起源の排出 | 地球平均気温上昇・海面上昇 |
| オゾンホール | フロン・ハロン | 南極上空のオゾン減少、地表UV増加 |
| ヒートアイランド | 土地利用・建物・人工排熱 | 都市が郊外より高温 |

- CO₂の急増：1800年頃の産業革命以降。化石燃料の燃焼。
- 放射強制力：地球のエネルギー収支を変える影響。正＝暖める、負＝冷やす。
- 海面上昇：極域の氷・氷河の融解＋海水の熱膨張。
- オゾン層：成層圏高度20〜30 km、紫外線を吸収。
- オゾン生成・消滅：チャップマン反応。
- オゾンは赤道上空で多く生成 → ブリュワー・ドブソン循環で高緯度へ。
- フロンが紫外線で分解 → 塩素が触媒的にオゾンを繰り返し破壊。

```text
ヒートアイランドの3原因
1. 土地利用：土・植物→アスファルト・コンクリート、蒸発冷却が弱い
2. 建物：風を妨げ、放射を閉じ込める
3. 人工排熱：自動車・エアコン・工場など
```

夜間は都市のコンクリート等が昼の熱を放出し続け、郊外より冷えにくい。

# 第4章 地球内部・地磁気（第7〜9回）

## 地震波から分かること

| | P波 | S波 |
|---|---|---|
| 種類 | 縦波 | 横波 |
| 速さ | 速い | 遅い |
| 伝わる物質 | 固体・液体・気体 | 固体のみ |

- 異なる物質の境界で反射・屈折。反射波が遅いほど境界は深い。
- 化学的区分：地殻 → マントル → 外核 → 内核。
- モホ面：地殻／マントル境界。
- グーテンベルク不連続面：マントル／外核境界。
- レーマン不連続面：外核／内核境界。

```text
P・S両方が届く → 地殻・マントルは固体
Pのみ届く      → Sが通れない外核は液体
P・Sが届かない → 大きな屈折を起こす境界（地震波の影）
```

| 地殻 | 主な岩石 | 厚さ |
|---|---|---:|
| 大陸地殻 | 花崗岩質 | 約30 km |
| 海洋地殻 | 玄武岩質 | 約7 km |

## 力学的区分・アイソスタシー

```text
リソスフェア：地殻＋硬いマントル最上部。硬く、割れて地震が起きる。
アセノスフェア：深さ約100〜200 kmの低速度層に対応。柔らかい「流れる固体」。
メソスフェア：その下のより硬いマントル。
```

- 地震波は硬い物質ほど速い。
- 低速度層：融解温度に近く岩石が柔らかいので、地震波が遅い。
- アセノスフェアは液体ではない。長時間で塑性変形する固体。
- アイソスタシー：リソスフェアがアセノスフェア上に浮いて釣り合う状態。
- 高い山ほど地殻が厚く、地下にも深い根を持つ。
- 氷床荷重で沈降、氷床が融けると隆起。フェノスカンディアでは今も隆起中。

## 地磁気

| 記号 | 名称 | 意味 |
|---|---|---|
| D | 偏角 | 磁北と真北の水平方向のずれ |
| I | 伏角 | 磁場の上下方向の傾き。北半球は下向き、南半球は上向き |
| F | 全磁力 | 地磁気全体の強さ |

- 地心双極子磁場：地球中心に棒磁石があると近似するモデル。実物の永久磁石ではない。
- キュリー温度：永久磁石が磁力を失う温度。地球深部は高温すぎ、永久磁石では地磁気を説明できない。
- 電流 → 磁場。磁石と金属を相対的に動かして電流が流れる現象＝電磁誘導。

```text
外核（液体の鉄を中心とする金属）が対流・自転で流動
→ 電流
→ 磁場
→ 地磁気（ダイナモ作用）
```

地磁気の3条件：金属の核、液体部分、液体金属の活発な流動。

# 第5章 大陸移動説→海洋底拡大→プレート（第10〜12回）

## 仮説の発展

```text
大陸と海洋の交代作用：上下運動で大陸・海洋が入れ替わる
        ↓ 否定される
ウェゲナー（1912年『大陸と海洋の起源』）：大陸は水平移動した
        ↓ 原動力を説明できず衰退
ヘス（1962年）：海洋底拡大説
        ↓
プレートテクトニクス：大陸・海洋底を含むプレート全体が水平移動
```

大陸移動説の根拠：

- 南米とアフリカの海岸線、大陸棚まで含めるとさらに一致。
- 離れた大陸にカタツムリ・ミミズ・淡水魚など同じ生物。
- 南米・アフリカの約1億1000万年前までの地層が一致。
- 大陸地殻（花崗岩質・厚い）と海洋地殻（玄武岩質・薄い）は異質。
- アイソスタシーにより地表が浮いている。

当時受け入れられなかった最大の理由：**大陸を水平移動させる原動力を説明できなかった。**

## 海洋底拡大説

```text
海嶺（中軸谷：伸張力でできた割れ目）
→ マグマ上昇・火山活動
→ 新しい海洋地殻
→ 海洋底が左右へ移動
→ 海溝で古い海洋プレートが沈み込み
```

- 海嶺：海底山脈。熱流量が大きく、火山活動が活発。
- 海嶺付近の海洋底は新しく、離れるほど古い。
- 海洋地殻が最古でも約2億年：海溝で沈み込み失われるから。
- 枕状溶岩：水中のマグマが急冷してできる丸い岩石。海底で新地殻が作られる証拠。
- アイスランド：大西洋中央海嶺の上。ギャオは引っ張られてできた大地の割れ目。

## プレートテクトニクス

- プレート＝リソスフェア＝地殻＋硬いマントル最上部。
- 世界の地震・火山はプレート境界に帯状に集中。

| 境界 | 動き | 別名・代表 |
|---|---|---|
| 発散境界 | 離れる | 海嶺 |
| 収束境界 | 近づく | 海溝・沈み込み・衝突 |
| 平行移動境界 | すれ違う | トランスフォーム断層 |

| プレート運動の考え | 内容 |
|---|---|
| 受動的 | マントル対流にプレートが流される |
| 能動的 | 海嶺からの滑り落ち、海溝で重いプレートが沈み込んで引っ張る |

- 太平洋：海溝が多く沈み込みの引っ張りがあるため比較的速い。
- 大西洋：大規模な海溝が少なく比較的遅い。

# 第6章 プレート境界・日本の地震（第13〜15回）

## 発散境界・平行移動境界

```text
発散境界：上昇するマントルが減圧で一部融解 → マグマ → 海洋地殻を生産
          正断層・地溝・中軸谷ができる

平行移動境界：プレートが横にすれ違う → トランスフォーム断層
```

- 東アフリカ地溝帯、紅海、大西洋中央海嶺：大陸分裂から海洋形成への連続例。
- 正断層：引っ張る力で生じる。ずれると地震、大地は陥没。
- トランスフォーム断層：主に海嶺と海嶺の間をつなぐ。実際にすれ違う区間だけ地震が活発。
- サンアンドレアス断層：すれ違う境界の代表。

## 収束境界

| 型 | 内容 | 地形・火山 |
|---|---|---|
| 沈み込み帯 | 海洋プレートが沈み込む | 海溝、島弧・陸弧、火山、深発地震 |
| 衝突帯 | 大陸プレート同士が衝突 | 巨大山脈。火山は少ない |

```text
沈み込み帯：海洋プレートが水を地下約100〜150 kmへ運ぶ
→ 岩石の融解温度が下がる
→ マグマ・火山活動

衝突帯：大陸地殻は軽く沈みにくい
→ 圧縮・逆断層
→ 地殻が厚くなり、巨大山脈
```

- 日本列島：沈み込み帯の島弧。
- アンデス：沈み込み帯の陸弧。
- ヒマラヤ：衝突帯。水の供給がないため活火山がほぼない。
- 新期造山帯：中生代以降、現在も継続。環太平洋・アルプス＝ヒマラヤ。
- 古期造山帯：古生代。ウラル・アパラチアなど。

## 記述問題の型

### 「なぜ低気圧で雨が降るか」

> 地上付近では摩擦により風が低気圧側へ吹き込み、摩擦収束が起きる。集まった空気は上昇し、断熱冷却で水蒸気が凝結するため、雲や雨が発生しやすい。

### 「なぜ外核は液体か」

> S波は固体しか伝わらないが、外核を通るはずのS波が観測されない。一方P波は観測されるため、外核は液体だと分かる。

### 「なぜ金星は高温か」

> 金星はアルベドが大きく有効放射温度は低いが、強い温室効果により地表からの赤外線が大気に吸収・再放射され、表面温度が非常に高い。

### 「なぜ大陸移動説が当時否定されたか」

> 海岸線・生物・地層などの証拠はあったが、大陸を水平方向へ移動させる原動力を説明できなかったため。

### 「なぜ台風は暖海上で発達するか」

> 暖海から水蒸気が供給され、上昇・凝結で潜熱が放出される。潜熱が上昇流と低圧化を強め、さらに湿った空気が流入する正の循環が起こるため。
